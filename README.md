# PeakFit Gym Landing Page

## Project Brief
A responsive single-page site for PeakFit Gym, a fictional Nairobi-based fitness center. Built to simulate a client project, focusing on user engagement, conversions, and accessibility. Live demo: [https://perisnwangombe-ops.github.io/PeakFitGym_Asgnmt1/]

## Technologies Used
- **Frontend**: HTML5, 
- **Tools**: Git/GitHub for version control, GitHub Pages for hosting
- **Design Principles**: Mobile-first, SEO-optimized, WCAG 2.1 compliant

## Setup Instructions
1. Clone repo: `git clone https://github.com/yourusername/peakfit-gym-landing.git`
2. Open `index.html` in a browser.
3. For dev: Edit files, commit via feature branches, merge to `develop`/`main`.
4. Deploy: Push to `main` for auto-build on GitHub Pages.




## Business Rationale
Targets urban professionals in Nairobi seeking convenient, results-oriented fitness. Hero CTA funnels to services; form captures leads. Scalable for e-commerce integration.

## Constraints & Testing
- Browsers: Chrome 120+, Firefox 115+, Safari 17+.
- Devices: Mobile (iPhone/Android), Tablet, Desktop.
- Performance: <2s load (optimize images in prod).
